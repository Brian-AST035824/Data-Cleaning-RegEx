# Presidential Data Cleaning Using Regular Expressions
This project demonstrates data cleaning using Python, pandas, and regular expressions (RegEx) in a Jupyter Notebook. It uses a presidential dataset to identify and clean inconsistencies in column names, text fields, dates, and age-related variables.

## Objectives
- Clean text values by removing leading, trailing, and repeated whitespace. - Use regular expressions to extract and standardize information from text. - Convert date columns into appropriate date formats. - Clean age and post-presidency duration fields. - Handle missing values and records indicating living individuals. - Improve data consistency and readability for further analysis.
## Tools and Technologies
- Python - pandas - Regular expressions (RegEx) - Jupyter Notebook

## Dataset
The project uses `presidents (1).csv`, included in this repository. The dataset contains information about presidents, including names, dates, ages, and post-presidency details.

## Project Workflow
1. Load the dataset into pandas.
2. Inspect the data and identify inconsistencies.
3. Clean text fields using string methods and regular expressions.
4. Extract and standardize age and duration information.
5. Convert valid dates into datetime values.
6. Handle missing values and check the cleaned results.
## Learning Outcomes
This project demonstrates practical use of regular expressions, pandas string operations, date conversion, and missing-value handling in a data-cleaning workflow.
